# استكشاف مركز بيانات للذكاء الاصطناعي

تطبيق مرئي ثلاثي الأبعاد لاستكشاف مركز البيانات، والانتقال من مستوى القاعة إلى الحامل ثم لوحة المعالج الرسومي ومكوناتها.

## المشاهد
تدعم بنية الواجهة مشاهد مركز البيانات والحامل واللوحة والمكوّن المحدد. تشمل الأجزاء القابلة للتركيز شريحة المعالج الرسومي والذاكرة عالية النطاق والمعالج المركزي والذاكرة والتبريد والربط الداخلي وتنظيم الطاقة.

تُعرض الحالة وأدوات الرجوع عبر طبقة واجهة فوق المشهد، مع انتقالات بين المستويات وحدّ لمعالجة أخطاء العرض.

## التنظيم
توجد الواجهة في `artifacts/ai-datacenter/`، والخادم في `artifacts/api-server/`. تتضمن مساحة العمل حزم عقود الواجهة والتحقق وعميل الطلبات وقاعدة البيانات داخل `lib/`.

## التقنيات
تستخدم الواجهة React وTypeScript والرسم عبر React Three Fiber. تستخدم مساحة العمل pnpm، ويوصف الخادم باستخدام Express وقاعدة PostgreSQL مع Drizzle، مع مخططات Zod وعقود OpenAPI.

## التشغيل والتوثيق
تُدار أوامر الفحص والبناء من ملفات `package.json`. يتضمن `replit.md` ملاحظات البيئة الأولية. هذه واجهة استكشاف بصري؛ لا تُعرض على أنها قياس حقيقي لكفاءة مركز بيانات أو تشغيل فعلي لمسرّعات.
